プライバシーポリシー

クレカケイ（以下「本アプリ」）は、利用者の家計に関する情報を扱うアプリとして、その取り扱いを以下のとおり定めます。

1. 取り扱う情報

本アプリが扱うのは、利用者が自分で入力した次の情報だけです。

  • 支出の記録（日付・金額・カテゴリ・メモ・支払元）
  • 固定収入・固定支出・積立の名前、金額、日付
  • 支払い方法の名前と引落日
  • 引落チェックの状態、アプリの表示設定

氏名、住所、電話番号、メールアドレス、位置情報、端末の識別番号などは取得しません。会員登録やログインもありません。

2. 情報の保存場所

入力した情報は、利用者のiPhoneの中（ブラウザのアプリ用保存領域）にだけ保存されます。開発者のサーバーや外部のサービスへ送信されることはなく、開発者が利用者の情報を見ることはできません。

3. 利用目的

保存した情報は、残額・引落予定・レポートなどを利用者の画面に表示するためだけに使います。

4. 第三者への提供

本アプリは情報を外部に送信しないため、第三者に提供することはありません。

5. 解析ツール・広告・Cookie

本アプリは、アクセス解析ツール、広告、トラッキング目的のCookieを使用していません。

6. 配信元（GitHub Pages）について

本アプリのファイルは GitHub, Inc. が提供する GitHub Pages から配信されています。アプリを開く際、通信の仕組み上、利用者のIPアドレスなどのアクセス情報が GitHub のサーバーに記録されることがあります。この情報は GitHub のプライバシーステートメントに従って扱われ、開発者は利用者の入力した家計の情報と結び付けることはできません。

7. バックアップファイル

設定の「書き出す」で作られるファイルには、本アプリの全データが含まれます。保存先（iCloud Drive など）や共有の範囲は利用者が選ぶもので、その管理は利用者の責任となります。他人に渡さないようご注意ください。

8. 情報の削除

ホーム画面から本アプリを削除すると、iPhoneの中のデータも削除されます。個別の記録は、アプリ内の編集画面から削除できます。

9. 安全管理

情報は利用者の端末内にのみ保存されるため、端末の画面ロックなどで端末自体を保護してください。

10. 本ポリシーの変更

機能の追加などに合わせて本ポリシーを変更することがあります。変更後の内容は、本アプリ内のこのページに掲載した時点から適用します。

ヘルプ

1. まずは設定しよう

設定タブで、上から順に「固定収入」「固定支出」「引落口座」「支払い方法」を登録しよう。カードは一覧から選ぶと、締め日と支払日が入る。

2. 大きな出費は積立に

車検や固定資産税など、年に1回や数年に1回の出費を積立に登録して、固定支出に反映しておこう。

3. 使ったらすぐ記録

金額を打ってカテゴリをタップするだけ。ホームの「残り」が、今月使っていい額。

4. 支払いタブにカードが出たら入金

期限の2週間前から、口座ごとに入金が必要な額が出る。入金や支払いが済んだらチェックしよう。

5. 月に1回バックアップ

設定の「書き出す」で、iCloud Drive などに保存しておこう。

ホーム

テンキーで金額を入れて、カテゴリをタップすると記録される。日付は上の日付をタップするとカレンダーで変えられる。支払元・メモ・支払回数（クレジットのときだけ）は、必要なときだけ変える。

カテゴリは長押しで並べ替えられる。最大12個。

履歴

月ごとの支出と、カテゴリ別の割合を表示する。記録をタップすると修正・削除できる。

支払い

その月の収入と請求を日付順に表示する。引落・支払いが済んだらチェックを付ける。金額をタップすると、その月だけ金額を変えられる。

期限の2週間前になると、入金が必要な額が口座ごとのカードで上に出る。チェックを付けるとカードは消える。

設定

固定収入・固定支出・引落口座・支払い方法・積立・カテゴリを登録する。ここの内容から、ホームの「使える額」と支払いタブの予定が自動で計算される。

データはこのiPhoneの中にだけ保存される。機種変更の前や月に1回は「書き出す」でバックアップを取っておこう。

今月使える変動費

来月の収入 − 来月の固定費 − 今月の支出済変動費。今月カードで使った分は来月払うので、来月の収支で計算する。分割・リボは1回分ずつ、買った月から順に各月の支出として数える。

カードの請求額

そのカード払いの固定支出 ＋ 締め日で区切った利用分。締め日までの利用は、支払月（当月・翌月・翌々月）の支払日に請求される。月末締め・翌月払いなら、前月1日〜末日の利用分が今月の請求になる。そのカードからチャージしている電子マネーの利用も含める。確定額を入れると、見込みより優先する。

入金の期限

口座引落は引落日の前日、自分で支払うものは支払期限の当日。同じ口座で期限が複数あるときは、後のカードに前の分も含めて表示する。

カードは期限の2週間前から琥珀色、期限の当日と過ぎたものは赤になる。

土日・祝日

引落日・入金日が土日・祝日・銀行の休業日（12/31〜1/3）に当たるときは、設定に従って直前または直後の平日にずらす。31日がない月は月末として扱う。

積立

1年あたりの合計を12で割った額を、固定支出に反映できる。次回の支払月が来月か再来月のときは、ホームに注意を出す。

データ

すべてこのiPhoneの中に保存され、外部には送信しない。
